# For my Angry Queen 🥺❤️

An adorable, highly interactive apology website designed for a very special person who is currently upset. It features a CSS opening envelope, custom typewriter apology diary pages, live-reacting cute bear stickers, sound effects, a dodging "No, still mad! 😡" button that runs away, an integrated grievance submission box that humorously rejects excuses, and a Make-up Date planner that sends response confirmations directly to WhatsApp!

## 🚀 Features
- **💌 Interactive Envelope**: A CSS-animated envelope that slides open on click.
- **🎵 Sweet Soundtrack**: Background instrumental melody plays on open, with toggle controls.
- **🌌 Particle Background**: Transparent floating canvas hearts and sparkles drifting upwards.
- **✨ Cute Reactions**: Live-reacting *Milk & Mocha* bear gifs based on interaction choices.
- **🔊 Tactile Sounds**: Cute pop sounds on hover/clicks, and success chimes when forgiveness is granted.
- **🚫 Runaway Grievance Handler**: The "No, still mad! 😡" button runs away on hover, eventually showing a grievance form that denies the anger and forces a sweet make-up path!
- **📅 Make-up Date Selector**: Choose a make-up date idea (Ice Cream & Cuddles, Pizza & Movie, Shopping Spree, Fancy Dinner) and select a calendar date.
- **💬 WhatsApp RSVP**: Instantly opens WhatsApp with a prefilled formatted message detailing the forgiveness confirmation and date selection!

## 📂 File Structure
- `index.html` — Layout and structure of screens.
- `style.css` — Styling, fonts, glassmorphism, keyframes, and responsiveness.
- `script.js` — Core logic, canvas particles, runaway calculations, audio controllers.
